## Field intent

| Field | Purpose |
|---|---|
| Narrative Cue | A compact action, relationship, process, and result for a visual scene. |
| Style | Shared rendering language only; do not copy the source image's game-model style. |
| Tags | Object class and immediately visible identity. |
| Theme | Subject matter tied to visible forms or use. |
| Color | Visible structural and material colors. |
| Scene | One-sentence original environment description; no proper name for character/building scene fields. |
| Form | Body, massing, or construction form. |
| Scale | Relative unit, machine, building, or map scale. |
| Distinctive Marks | Three or more specific anchors that separate this object from its faction peers. |
| Silhouette | Outer contour readable at a glance. |
| Material | Visible surface materials. |
| Equipment or Components | Weapons, tools, architectural parts, or landmarks. |

## Acceptance checklist

- The record belongs to exactly one of `角色`, `建筑`, or `场景`.
- Chinese and English names are paired with the same original object.
- Every field is non-empty in both languages and item order matches.
- `Distinctive Marks` has at least three specific visible anchors.
- No `Pose or Composition` or `Lighting` field remains.
- Narrative and scene do not repeat the same sentence.
- Role English sections are no longer than 950 characters.
- Image evidence identifies the object, URL, source type, image type, and verification state.
- Unconfirmed facts are listed in `BLOCKED.md` with sources and temporary handling.
